# Lotería Doloreña (TDD)

Pruebas y código del manual "Manual paso a paso con TDD - Lotería Doloreña".

## Cómo ejecutar las pruebas
```
flutter pub get
flutter test
```
Resultado esperado: 17 pruebas en verde (baraja 5, tabla 4, verificador 6, motor 2).

Para jugar: `flutter create .` (genera android/ios) y luego `flutter run`.
